
OmniTask AI: Agentic Document & Workflow Optimizer

Live Demo: onrender.com
OmniTask AI is an intelligent, multi-agent workflow automation tool developed for the Razorpay AI Buildathon that converts unstructured documents and PDFs into structured milestone databases.

Key Highlights

• Architecture: Utilizes a Flask backend, PyPDF extraction, and Google Gemini AI to parse inputs and stream structured JSON to a dynamic Bootstrap 5 dashboard.
• Tech Stack: Python 3.x, Flask, PyPDF, Google Gemini API, HTML5, CSS3, and Bootstrap 5.


Quick Setup
git clone https://github.com
cd omnitask-ai
pip install -r requirements.txt
